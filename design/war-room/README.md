# War Room TUI design

Visual spec for `conduit watch` as a terminal UI (issue #89, PRD `prd/drafts/war-room.md`).
Exported from the Claude Design "War Room TUI" page on 2026-09-28, after four rounds on the
web layout and one round constraining it to a character grid.

This is a design reference, not production code. The real TUI renders from the journal
projection with `@opentui/react`.

## Rendering rules

- A fixed grid, 160 columns by 45 rows minimum. Every element occupies whole cells.
- One font size. Emphasis is bold, normal, or dim.
- Borders and dividers are box-drawing characters (`─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴`).
- Waterfall bars are full blocks with eighth blocks (`▏▎▍▌▋▊▉`) for partial ends. When two
  segments meet inside one cell, the left color is the foreground of an eighth block and the
  right color is its background (see `bar()`).
- Working segments animate by swapping `█` for `▓` every fourth cell. The overdue part of a
  held bar is `▒` in the overdue color. The rework marker is `«`. The OVERDUE state label
  blinks between an overdue fill and overdue text.
- Header meters are 8 cells of `█`, eighth blocks, and `░`. At 80% or more the whole meter
  gets the loud fill.
- There is no hover. The selected row's details go in the status bar on row 42. The footer
  carries key hints: `j/k` select, `enter` open drawer, `t` tool ticks, `r` replay, `esc` close.
- The drawer is 60 columns wide and its body scrolls, with an indicator in the last column.

## Using the golden frames

`tui-reference.js` draws from a hard-coded scenario (`CARDS`, `CALLS`, `FRAMES`). A journal
fixture that reproduces that scenario lets the real TUI's `captureCharFrame()` output be
compared against `golden/*.txt`. Expect small differences where the real projection has
data the mock did not; treat a difference as a question about the design or the projection,
and update the golden file only on purpose.

The mock scenario shows some fields the journal may not record yet (for example, a
finding's severity). Where the journal lacks a field, the TUI renders "not recorded" and
logs the gap (PRD FR-13) instead of copying the mock.
